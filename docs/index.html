CDPM framework. An eight-cable manipulator follows a circular path; cable colour shows tension from the QP solver.

Abstract

An open Python framework for studying eight-cable driven parallel manipulators: geometry and kinematics, optimal tension distribution, trajectory simulation and publication-quality visualisation in one package. Tension distribution is posed as a strictly convex quadratic programme with cable and actuator limits and solved with warm-started OSQP for real-time use, with SLSQP and null-space projection as fallbacks. Circular, helical, 3-D Lissajous and multi-waypoint quintic trajectories are built in, and every run is deterministic for reproducible experiments.

Overview

Method

  • Robot model. Modular 8-cable robot class with frame and platform geometry, inverse kinematics and the 6×8 structure matrix.
  • Tension solver. Strictly convex QP with minimum and maximum tension and actuator limits, warm-started OSQP; automatic fallback to SLSQP or analytical null-space projection.
  • Trajectories. Circular, helical, 3-D Lissajous and multi-waypoint quintic profiles, all smooth and differentiable.
  • Simulation. Quasi-static and dynamics-corrected simulation with per-step logging of pose, tensions and solver status.
  • Visualisation. 3-D animation with tension colour mapping, platform trail and summary plots, exported as MP4.
